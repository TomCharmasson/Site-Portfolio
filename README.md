# Portfolio Site

Ce projet est un site portfolio personnel qui présente mes projets, compétences et informations personnelles. 

## Structure du projet

Le projet est organisé comme suit :

```
portfolio-site
├── src
│   ├── index.html         # Point d'entrée du site
│   ├── css
│   │   └── styles.css     # Styles CSS pour le site
│   ├── js
│   │   └── script.js      # Code JavaScript pour les fonctionnalités interactives
│   └── assets
│       └── fonts          # Dossier contenant les fichiers de police
├── .gitignore             # Fichiers et dossiers à ignorer par Git
└── README.md              # Documentation du projet
```

## Installation

1. Clonez le dépôt :
   ```
   git clone <URL_DU_DEPOT>
   ```
2. Accédez au dossier du projet :
   ```
   cd portfolio-site
   ```

## Utilisation

Ouvrez le fichier `src/index.html` dans votre navigateur pour visualiser le site.
